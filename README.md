# Tales of the Forlorn
Tales of the Forlorn is a dark fantasy world based on the High Middle Ages and the mythologies of that time.

Everything in this world is either based on folklore, mythology, medieval texts, or my own imagination, and goes for that specific aesthetic that is mysterious and terrifying without grandeur. Although magic is rare and just strong enough to rival warriors without overpowering them, many still view magic as something that should be respected, feared, or hated.

Since this world is a spin-off from Aldraheimr, there will be many similar elements. But of course, there will be some differences in the design direction, for example, more magical integration in societies and more effort in creating original cultures.
